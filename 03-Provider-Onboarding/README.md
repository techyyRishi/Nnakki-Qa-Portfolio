
# Provider Onboarding Testing

## Project
Nnakki – Service Marketplace

## Overview
This section covers provider registration and onboarding workflows, including personal information, contact information, professional details, and provider account setup.

## Modules Covered
- Provider Signup
- Provider Registration
- Personal and Contact Information
- Professional Information
- Provider Details
- Onboarding Form Validation
- Onboarding Navigation

## Testing Scope

### 1. Provider Registration
- Provider signup flow
- Required field validation
- First Name and Last Name input
- Email field validation
- Password field validation
- Phone / Cell Number field
- Province selection
- User Type / Role selection
- Terms and Conditions acceptance

### 2. Onboarding Form
- Personal information submission
- Contact information validation
- Professional information submission
- Mandatory field validation
- Valid and invalid data handling
- Navigation between onboarding steps

### 3. Account Creation
- Successful provider registration
- Registration email verification
- Newly created provider login
- Duplicate account validation
- Data submission and persistence

## Test Case Coverage
- Positive Functional Testing
- Negative Functional Testing
- Field Validation Testing
- UI Testing
- Workflow Testing

## Test Execution Platforms
- Windows
- Android
- iOS
