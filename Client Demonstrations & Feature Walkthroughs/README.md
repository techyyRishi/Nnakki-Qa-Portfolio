# Client Demonstrations & Feature Walkthroughs

## Overview

In addition to manual QA activities, I was involved in client-facing product demonstrations and feature walkthroughs for the Nnakki platform.

Nnakki was developed for a South African client. I delivered an end-to-end demonstration of the platform on the project delivery day, explaining the application's workflows and functionality.

I also created screen recordings with voice-over explanations whenever the client needed clarification about specific features or Sharetribe functionality.

## My Responsibilities

### 1. End-to-End Client Demonstration
- Delivered an end-to-end demonstration of the Nnakki platform to the client on the delivery day.
- Demonstrated key application workflows and explained the functionality of different modules.
- Helped the client understand the delivered product through a practical walkthrough.

### 2. Screen Recording & Voice-over Explanations
- Created screen recordings to explain specific application features and workflows.
- Added voice-over explanations to make functional behaviour easier to understand.
- Shared recorded walkthroughs with the client to address questions and clarify functionality.
- Explained relevant Sharetribe platform functionality whenever clarification was required.

### 3. Feature Walkthrough Documentation

Examples of recorded walkthrough topics include:

| Feature / Topic | Demonstration |
|---|---|
| Provider Filtering | Provider filtering workflow |
| Listing Approval | Listing approval process |
| Provider Account | Provider account-related workflow |
| Provider Details | Provider information-related screens |
| Bank Details | Updating bank and payout details |
